# INTERVAL COSMOS v2.0.5 — Phase 8 / PC Controls

## Status

**PASS — real-browser verification completed on 2026-08-19.**

Phase 8 adds desktop keyboard control without changing the touch-first mobile gameplay UI.

## Implemented controls

- Answer keys are configurable from `SETTINGS > PC KEY CONFIG`.
- `Space` remains the replay key.
- `R` retries from result screens.
- `Esc` backs out / closes the current compatible screen.
- `Esc` and `Space` are reserved and cannot be assigned as answer keys.
- Existing editable text fields remain protected from game shortcuts.

## Default answer mapping

- P1: `1`
- m2: `M → 2`
- M2: `2`
- m3: `M → 3`
- M3: `3`
- P4: `4`
- TT: `T`
- P5: `5`
- m6: `M → 6`
- M6: `6`
- m7: `M → 7`
- M7: `7`
- P8: `8`

The optional prefix key may be reassigned or cleared. Decision keys are required.

## Input methods

Two input methods are available and persist locally.

### 2-stage input

Default mode.

Example: short 3rd = `M → 3`.

The prefix is armed first, then the decision key is pressed.

### Simultaneous input

Example: short 3rd = `M + 3`.

The prefix key is held while the decision key is pressed. A plain `3` still answers major 3rd immediately.

This avoids adding a timing delay to direct major/perfect interval answers.

## KEY CONFIG interaction polish

Verified behavior:

- Unassigned prefix cells are visually blank; no large dash is shown.
- Decision-key cells use a subtle red accent.
- The selected capture cell alone enters a stronger red learning state.
- User-facing `REC` wording is not used.
- Capture state reads `入力待ち…`.
- Header instruction reads `希望するキーを押してください。`.
- `ESCでキャンセル` is shown during capture.
- Successful capture gets a short confirmation flash.
- Scroll position is preserved when capturing keys near the bottom of the list.
- Input-mode switching changes `→` / `+` notation consistently in KEY CONFIG and gameplay hints.

## Mobile behavior

Gameplay keyboard hints are desktop-pointer-only.

Real-browser mobile emulation was checked on 2026-08-19 and confirmed that PC key labels such as `3`, `M→3`, and `M+3` are not shown in the touch/coarse-pointer layout. The game layout remained intact.

## Known deferred issue

An intermittent, momentary mode-select screen flicker can still occur around KEY CONFIG at an unclear timing. It does not block configuration or gameplay and is tracked separately in GitHub Issue #7 for later UI/UX polish.
