# v2.0.5 Pre-release hardening

## Supabase client unification — REQUIRED BEFORE RELEASE

実ブラウザのDevToolsで以下の警告を確認。

`Multiple GoTrueClient instances detected in the same browser context.`

### 原因

現在、認証を所有する `cloud.js` のSupabase clientとは別に、以下の拡張モジュールが追加のclientを生成している。

- `phase2-recovery-v205-fixed.js`
- `phase5-progression-v205.js`

同一storage keyを使用する複数のGoTrueClientが同一ブラウザコンテキストに存在するため警告が発生する。

### 正式対応

警告を抑制するだけの対応は行わない。

- Supabase clientの生成・Auth session所有者を `cloud.js` の1インスタンスへ統一する
- 拡張モジュールは共有clientまたは `cloud.js` のRPC wrapperを利用する
- recovery / progressionモジュールから `window.supabase.createClient(...)` を除去する
- 同一ページ内のGoTrueClientを1個にする

### 必須回帰テスト

統一後、少なくとも以下を実ブラウザ確認する。

1. 既存学生アカウントの自動ログイン
2. 新規学生登録
3. 6桁PINによる別端末追加
4. 学籍番号＋復旧コードによる自己復旧
5. ランキング取得・公開
6. 学習履歴取得
7. MY COSMOS取得
8. 実績・デイリー進行
9. 代表実績の保存
10. DevTools Consoleに `Multiple GoTrueClient` 警告が出ないこと

### 扱い

Phase 5の機能検証自体はPASS。これは機能追加フェーズを止めるためのUI課題ではないが、v2.0.5をmainへリリースする前に必ず解消するpre-release blockerとする。
