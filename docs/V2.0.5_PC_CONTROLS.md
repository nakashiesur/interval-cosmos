# INTERVAL COSMOS v2.0.5 — PC controls

## 方針

既存の回答キー配列を変更せず、通常プレイと課題プレイで同じ操作感に揃える。

回答キーの新しい割り当て方式（度数＋修飾キー等）は、現行操作を壊さないよう別途検討する。

## 回答キー

| 音程 | Key |
|---|---|
| P1 | 1 |
| m2 | 2 |
| M2 | 3 |
| m3 | 4 |
| M3 | 5 |
| P4 | 6 |
| TT | 7 |
| P5 | 8 |
| m6 | 9 |
| M6 | 0 |
| m7 | Q |
| M7 | W |
| P8 | E |

PC（hover + fine pointer）では回答ボタン右上へ小さなキーキャップ表示を追加する。タッチ端末では表示しない。

## 共通ショートカット

- `Space`：問題音を再生（既存ゲームエンジンの処理を継続利用）
- `R`：RESULTからRETRY
- `Esc`：安全に戻れる画面では1階層戻る／閉じる

## Escの安全設計

誤操作によるプレイ破棄を避けるため、ゲーム進行中のEscでは終了させない。

- 通常の時間制限プレイ中：従来の「長押しで終了」を維持
- 課題プレイ中／カウントダウン中：Escで中断しない
- 課題一覧・モード選択・RESULT等：Escで戻る／閉じる
- Admin Dashboard：Escで閉じる
- SETTINGS / RANKING / PLAYER modal：既存の閉じるボタンを経由して閉じる

## 入力欄の保護

以下にフォーカスがあるときはPC共通ショートカットを発火しない。

- input
- textarea
- select
- contenteditable
- role=textbox

`Cmd/Ctrl/Alt`を伴うキー、IME変換中、キーリピートも無視する。
