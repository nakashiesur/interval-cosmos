# iPhone / iPad first physical-device pass

Same-Wi-Fi preview: start `python3 scripts/serve-device-test.py --host <Mac LAN IP> --port 8896` and open that HTTP address in Safari. Keep Mac awake. This server only exposes assets listed in sw.js and dedicated Fresh Build Test configuration; repository metadata, SQL, work notes, tests and directory listings return 404. Default host stays loopback. No router forwarding or external publication.

This HTTP preview covers layout, touch and audio. Service workers require a secure context on iOS, so it is NOT an offline/PWA/installation acceptance environment. A trusted HTTPS test deployment is required for that later pass. Never bypass browser certificate warnings.

First user pass on each device:
1. Open app and choose guest. Do not enter a real student number or recovery credential.
2. Start PRACTICE, replay sound, answer several questions; report silent, delayed or interrupted audio.
3. Open settings and learning history; verify touch controls, vertical scrolling, close buttons and portrait/landscape layout.
4. Report device model, iOS/iPadOS version and the screen/action where any issue appeared. No account secrets are needed.

Registered MY COSMOS / artwork and real offline/multiple-device tests follow after connectivity/audio pass and secure test URL setup. No production deployment or main merge is implied.
