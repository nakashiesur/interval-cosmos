# INTERVAL COSMOS v2.0.5 — Assignments

## Goal
Teacher-created common assignments for all students.

## Rules
- Teacher identity is `players.account_type = 'staff'`; this does not imply `is_admin`.
- Students can see only published assignments.
- Each assignment defines mode, interval set, start time, deadline, optional target score, and optional target accuracy.
- Attempts are unlimited during the active window.
- `assignment_bests` keeps the highest-score attempt. `achieved` becomes true once any attempt satisfies all configured targets.
- Assignment plays use `play_sessions.source = 'assignment'` and never publish to the public ranking.
- Student assignment data remains part of learning history and progression.

## UI
Student:
- ASSIGNMENTS button on the home screen.
- Shows OPEN / COMING / CLOSED and BEST / ACCURACY / ATTEMPTS.
- Active assignments can be played repeatedly.

Teacher:
- TEACHER ASSIGNMENTS button.
- Create and publish assignments.
- Publish/unpublish.
- View all students' attempt count, best score, best accuracy, and achieved status.

## Security
All assignment mutations and teacher-only reads use SECURITY DEFINER RPCs that verify the current player is staff (or admin). Direct browser mutation of the underlying tables remains disabled.

## Phase 6 browser checks
1. Teacher creates a published assignment.
2. Student account sees the assignment.
3. Student plays once; attempt becomes 1.
4. Student plays again with a lower score; BEST stays at the higher score and attempts becomes 2.
5. Student reaches target; ACHIEVED persists.
6. Teacher results show the student's attempt count and best.
7. No assignment attempt appears in ONLINE RANKING.
