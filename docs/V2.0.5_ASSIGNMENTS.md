# INTERVAL COSMOS v2.0.5 — Assignments

## Goal
Administrator-created common assignments for all students.

## Account / permission model
- `players.account_type = 'student'`: normal player account.
- `players.account_type = 'staff'`: normal player account for faculty/staff. Staff status itself grants no management privileges.
- `players.is_admin = true`: the sole internal administrator. Only this account may create/publish assignments or read all-student assignment results.
- For the intended production deployment, the internal administrator is a single account; ordinary faculty/staff only play the game.

## Rules
- Students and ordinary staff can see published assignments as players.
- Each assignment defines mode, interval set, start time, deadline, optional target score, and optional target accuracy.
- Attempts are unlimited during the active window.
- `assignment_bests` keeps the highest-score attempt. `achieved` becomes true once any attempt satisfies all configured targets.
- Assignment plays use `play_sessions.source = 'assignment'` and never publish to the public ranking.
- Student assignment data remains part of learning history and progression.

## UI
Player:
- ASSIGNMENTS button on the home screen.
- Shows OPEN / COMING / CLOSED and BEST / ACCURACY / ATTEMPTS.
- Active assignments can be played repeatedly.

Internal administrator only:
- ADMIN ASSIGNMENTS entry.
- Create and publish assignments.
- Publish/unpublish.
- View all students' attempt count, best score, best accuracy, and achieved status.

## Security
All assignment mutations and all-student reads use SECURITY DEFINER RPCs. The Phase 6 permission correction in `sql/assignments-admin-only-v2.0.5.sql` changes the legacy `is_current_teacher()` helper so it returns true only when `players.is_admin = true` and the account is not suspended. Ordinary `staff` accounts do not pass this check.

The helper name is retained temporarily for compatibility with the initial Phase 6 RPCs; it no longer means that faculty/staff accounts have management rights. Direct browser execution of the helper is revoked by the correction patch.

## Phase 6 browser checks
1. Administrator creates a published assignment.
2. Student account sees the assignment.
3. Student plays once; attempt becomes 1.
4. Student plays again with a lower score; BEST stays at the higher score and attempts becomes 2.
5. Student reaches target; ACHIEVED persists.
6. Administrator results show the student's attempt count and best.
7. No assignment attempt appears in ONLINE RANKING.
8. Ordinary staff account opens ASSIGNMENTS as a normal player and cannot access management RPCs.
