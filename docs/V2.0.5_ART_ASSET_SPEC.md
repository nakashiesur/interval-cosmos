## Shared visual direction

Dark space / cyan / music / SF, with recognizable silhouettes and playful mascot details. Keep gameplay notation separate from decorative artwork. Course badges identify a course; avatars identify a player. Do not combine the two assets. Use shape and silhouette as well as color so adjacent identities remain distinguishable.

- No baked-in text, player name, score, title, course label, or lock symbol. Render labels and state in accessible HTML.
- Transparent background; sRGB; square artboard; central subject within the inner 76% to survive circular crops.
- A clean small-size variant must work at 24–32 CSS px. Avoid tiny stars, thin lines, or dense instrument detail at that size.
- Preserve the current database IDs. Asset filenames do not rename accounts, courses, achievements, or frames.
- All motifs below are proposals awaiting visual approval.

## Frames

IDs: `normal`, `bronze`, `silver`, `gold`, `platinum`, `cosmic`, `aurora`, `supernova`, `event_horizon`.

Frames are separate transparent ring overlays. Keep the avatar's central 70% unobscured and an outer 8% bleed zone for glow. Static artwork is required for every animated frame. Existing animated flags and unlock rules remain authoritative.

Animate transforms/opacity in CSS with 6–12 second loops; avoid GIF/video as the default avatar frame. Disable decorative movement under `prefers-reduced-motion: reduce`, and pause hidden/offscreen animation. Avoid flashes, rapid luminance changes, and layout-affecting animation.

## Delivery sizes and formats

| Family | Target CSS sizes | Export sizes | Preferred format |
| --- | --- | --- | --- |
| Course badges | 24, 32, 48 | 48, 64, 96, 192 px | SVG for original vectors; WebP for painted art |
| Player / teacher | 32–112 | 64, 128, 256, 512 px | Transparent WebP + lossless PNG master |
| Achievement | 28–64 | 64, 128, 256 px | SVG or transparent WebP |
| Frame | 32–112 plus glow | 128, 256, 512 px | SVG or transparent WebP + CSS movement |

Current reference sizes include MY COSMOS desktop 112 px and public-profile desktop/mobile 82/64 px; compact layouts may override these. Verify final computed sizes before export. Provide at least 2x density for each slot; use `srcset`/`sizes`, explicit width/height, and `object-fit: contain`.

Use SVG only for actual vector designs, not raster files wrapped in SVG. Strip metadata and external references. Keep editable masters out of runtime bundles. Proposed budget: <=30 KB for a compact badge, <=80 KB for a 256 px avatar, <=120 KB for a 512 px frame. Optimize against visual quality before enforcement.

## Paths and manifest

Proposed paths: `assets/art/v1/courses/{id}-{size}.webp`, `avatars/{id}-{size}.webp`, `achievements/{id}-{size}.webp`, `frames/{id}-{size}.webp`.

Create a manifest with catalog ID, family, revision, available sizes, fallback, and optional static/animated frame pairing. Decorative images use empty alt text when the adjacent text gives the same identity; otherwise use a short meaningful label. Missing art must retain a working placeholder.
