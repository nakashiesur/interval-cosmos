# INTERVAL COSMOS v2.0.5 — Phase 5 Progression

## Scope

Phase 5 adds the long-term progression layer agreed for v2.0.5:

- achievements
- main title + title collection
- point-based frame growth
- combination / secret frames
- 3 daily missions per day
- featured achievements (up to 3) for the public profile card
- unlock presentation

Daily missions never modify the gameplay score. Their points only feed profile/cosmetic growth.

## Frame progression

Point-growth route:

`NORMAL → BRONZE → SILVER → GOLD → PLATINUM → COSMIC`

Existing thresholds from the Phase 1 schema are retained:

- NORMAL: 0 pt
- BRONZE: 100 pt
- SILVER: 300 pt
- GOLD: 700 pt
- PLATINUM: 1200 pt
- COSMIC: 2000 pt (animated)

Special combination frames:

- AURORA — visible combination unlock: `PRECISION PILOT` + `COSMOS EXPLORER`
- SUPERNOVA — hidden combination unlock
- EVENT HORIZON — hidden combination unlock

Hidden locked content is returned to the player UI as `???` without exposing the exact condition.

## Achievement philosophy

Visible achievements cover the range expected to build useful interval-recognition skill:

- total play count
- perfect-accuracy sessions
- combo milestones
- TEXT / KEYS / HYPER / EAR LINK use
- all-mode exploration
- 13-interval mastery
- 3 / 7 / 14 day streaks
- public ranking milestones

High-end challenge achievements are hidden as `???` until unlocked.

Examples of visible milestones:

- FIRST SIGNAL — first saved session
- ORBIT STARTER — 5 sessions
- ORBIT REGULAR — 20 sessions
- PRECISION PILOT — 20+ answers at 100%
- COMBO DRIVER — combo 10
- CHAIN REACTOR — combo 30
- COSMOS EXPLORER — play all five ranked modes
- INTERVAL NAVIGATOR — all 13 intervals with sufficient sample count and ≥80%
- SEVEN DAY ORBIT — 7 day streak
- TOP TEN / PODIUM / NUMBER ONE — public hall ranking milestones

Hidden examples include advanced EAR LINK accuracy, very long combo, all-mode perfect play, and the SINGULARITY combination achievement.

## Titles

Achievement rewards unlock titles. One title is equipped as the main title and is shown on rankings/public profile.

Seeded title set includes:

- FIRST SIGNAL
- ORBIT REGULAR
- PRECISION PILOT
- COMBO DRIVER
- CHAIN REACTOR
- COSMOS EXPLORER
- INTERVAL NAVIGATOR
- SEVEN DAY ORBIT
- TOP TEN
- NUMBER ONE
- hidden endgame titles

## Daily missions

Each player receives three deterministic-but-varied missions per JST calendar day. The same player sees the same three missions for that date across devices.

Mission pool includes light goals such as:

- play 2 sessions
- answer 15 questions
- get 10 correct answers
- reach combo 5
- play TEXT / KEYS
- play two distinct modes
- complete a clean 100% session with at least 5 answers
- complete a ≥90% session with at least 5 answers
- play HYPER DRIVE once
- play EAR LINK once

Rewards are 10–20 COSMOS PT and do not affect game scores.

## Idempotency / multi-device behavior

`evaluate_my_progress()` recomputes progression from saved server data and uses `ON CONFLICT DO NOTHING` for unlock rows. This makes repeated evaluation safe and supports multiple linked devices.

COSMOS PT is recomputed from:

1. points of unlocked achievements
2. rewards from completed daily missions

Frame unlocks and title unlocks can therefore be reconstructed from durable records rather than relying on a one-time client event.

## Public profile

Players may select up to 3 unlocked achievements as featured achievements. These are the only achievement details surfaced on another player's public profile card.

Main title and equipped frame continue to sync through `players → public_profiles`.

## Installation order

1. Existing Phase 1 v2.0.5 database must already be present.
2. Existing Phase 2 device-link SQL must already be present.
3. Run `sql/progression-v2.0.5.sql` in Supabase SQL Editor.
4. Pull `v2.0.5-dev` and restart the local build.
5. Open `MY COSMOS`; existing saved play sessions are evaluated retroactively.
