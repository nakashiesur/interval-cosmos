# INTERVAL COSMOS v2.0.5 — Master Progress Ledger

This document is the working progress ledger for the agreed v2.0.5 master plan. It exists to prevent local fixes or release-blocker work from obscuring the original development sequence.

## Operating rule

The agreed phase plan remains the project master. Tactical reordering is allowed only when a blocker, regression, or verification dependency makes it safer to do so.

Status labels:
- **PASS** — implemented and sufficiently verified for this phase
- **IMPLEMENTED / VERIFY** — implementation exists; targeted or integrated verification remains
- **IN PROGRESS** — active work remains
- **NOT STARTED** — planned work has not begun in earnest
- **DEFERRED POLISH** — non-blocking issue intentionally left for later UI/UX polish

## Release gate

Do not call the build final `v2.0.5` until the following six protections are demonstrated:

1. Accounts are not broken.
2. Rankings are never published unintentionally.
3. Multi-device use does not lose records.
4. Student numbers cannot duplicate after normalization.
5. Non-admin users cannot operate the admin system.
6. Offline recovery does not duplicate scores.
